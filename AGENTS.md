# tomzlab-web — Repository Instructions

Always read current `uichat-mira/.github/AGENTS.md` and its routed guidance.

## Product and ownership
- `tomzlab.cn` is the individual noncommercial website “党靖涛的记事本”, not a business or paid service. Publicly approved ICP/security registration numbers may be displayed; never commit private filing documents, credentials, addresses, or PII.
- **Folio dev consumer experiment:** Folio owns Header, structured Footer, Pearl theme, search, React routes, Markdown rendering, canonical metadata, sitemap, 404 and static output. The consumer customizes the homepage body (`slots.home`), brand (`slots.headerBrand`), and native external-publication lists (`slots.pages` + `FolioListPage`) using public interfaces. Do not re-create Folio page shells.
- `/notes`, `/weekly`, `/projects` use **Folio's exported `FolioListPage`** (never hand-written Markdown catalogs); `scripts/sync-source-index.py` projects original RSS into ignored `lists.generated.json`. Original `projects.md` is the sole authoring source for the four project entries. Folio `type: page` documents retain route metadata for static SEO only; the consumer's build adapter substitutes the *same* Folio list React tree as the static root body because Folio #196 does not yet serialize `slots.pages`. `/about` remains a Folio Markdown page; `/journal` remains a Folio collection. Preserve original publishers' ownership; no copied articles or fabricated posts.
- Former `notes.html`, `weekly.html`, `projects.html`, `about.html` URLs are **noindex redirect aliases only**, generated by `write-legacy-redirects.mjs`. The old hand-built HTML/CSS/JS content pages are retired. Folio is the single route and rendering source of truth.
- Bookshelf subscription: Folio dev owns the browser fetch lifecycle via `useFolioJsonSubscription`; publisher `books/catalog.json` owns current metadata and chapter links. The consumer owns strict trust-boundary validation and a dated SSR/no-JS fallback; never reintroduce `sync-books.py` HTML scraping. A local test endpoint must not be promoted to production.
- Feed failures must be visible: generator logs source errors and writes a labeled dated offline snapshot. Never claim a fallback is fresh or silently convert unavailable feeds into fabricated posts.
