# tomzlab-web — Repository Instructions

Always read current `uichat-mira/.github/AGENTS.md` and its routed guidance.

## Product and ownership
- `tomzlab.cn` is the individual noncommercial website “党靖涛的记事本”, not a business or paid service. Publicly approved ICP/security registration numbers may be displayed; never commit private filing documents, credentials, addresses, or PII.
- **Folio dev consumer experiment:** Folio owns Header, structured Footer, Pearl theme, search, React routes, Markdown rendering, canonical metadata, sitemap, 404 and static output. The consumer customizes the homepage body (`slots.home`), brand (`slots.headerBrand`), and native external-publication lists (`slots.pages` + `FolioListPage`) using public interfaces. Do not re-create Folio page shells.
- `/notes`, `/engineering`, `/weekly`, `/projects` use **Folio's exported `FolioListPage`** (never hand-written Markdown catalogs); `scripts/sync-source-index.py` projects Tomz.io JSON Feed and Mira engineering RSS into ignored `lists.generated.json`. Original `projects.md` is the sole authoring source for the four project entries. Folio `type: page` documents retain route metadata for static SEO only; the consumer's build adapter substitutes the *same* Folio list React tree as the static root body because Folio #196 does not yet serialize `slots.pages`. `/about` remains a Folio Markdown page; `/journal` remains a Folio collection. Preserve original publishers' ownership; no copied articles or fabricated posts.
- Former `notes.html`, `weekly.html`, `projects.html`, `about.html` URLs are **noindex redirect aliases only**, generated by `write-legacy-redirects.mjs`. The old hand-built HTML/CSS/JS content pages are retired. Folio is the single route and rendering source of truth.
- `/notes` shows only Tomz.io life, reading, essay, and personal-thinking entries; `/engineering` shows only Mira engineering/product RSS. Never concatenate those sources in either route. Both render FolioListPage from their own publisher, own metadata route, and own source freshness status.
- Publication subscriptions: this consumer owns HTTPS discovery, JSON Feed, Book Catalog validation and browser transport/cache through `publication-contract.mjs` / `usePublicationResource`. Folio remains the UI/router only. Do not require the unmerged Folio subscription Hook, scrape publisher HTML, or classify Tomz.io issues from URL paths. Keep the dated SSR/no-JS fallback.
- Feed failures must be visible: generator logs source errors and writes a labeled dated offline snapshot. Never claim a fallback is fresh or silently convert unavailable feeds into fabricated posts.
